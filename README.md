# Student Management System

A console-based Student Management System developed using Python and SQLite.

## Features

- Add student records
- View all students
- Search students by ID
- Update student information
- Delete student records
- SQLite database storage
- Input validation
- Exception handling

## Technologies Used

- Python
- SQLite
- SQL

## Concepts Used

- Functions
- Loops
- Conditional Statements
- Exception Handling
- SQL CRUD Operations
- Database Connectivity
- Input Validation

1. Download or clone this repository.
2. Open the project folder.
3. Run:

```bash
